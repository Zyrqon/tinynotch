Features

Everything lives in the notch

No dock icons, no menu bar clutter. The island appears when something happens and folds away when you don't need it.

🤖

AI agents with approvals

Watches codex and opencode sessions. Approve or deny tool use right from the notch, see live output and a red badge the moment an agent waits for you.

🧰

100 built-in tools

Text cleanup, converters, calculators, screenshots, OCR, PDF merge, git, QR codes, pomodoro, games — a searchable toolbox behind one tap.

🎵

Music & AirPods

Now-playing card with progress and controls. AirPods case, buds and MacBook battery in one iPhone-style sheet.

📋

Clipboard history

Every copy lands in the island. Pin, search, re-paste. One-time codes are caught automatically and shown as a tappable card.

🧲

Shelf

Drag files onto the notch to hold them, drag them back out anywhere. A pocket for the thing you're moving between apps.

🔔

Real notifications

Charging, downloads, OTP codes, agent approvals and completions slide out of the notch — one style, zero noise.

🖨️

Printer status

Live Bambu Lab printing progress: percent, layers, nozzle and bed temps — right in the notch.

🧹

Memory janitor

Closes idle agent browsers and returns RAM on a schedule you control.

Build

From source in two commands

No Xcode required — Command Line Tools are enough. macOS 14 Sonoma or newer, Apple Silicon.

# clone and build
git clone https://github.com/Zyrqon/tinynotch.git
cd tinynotch && swift build -c release
# the app lands in .build/release/TinyNotch.app
1

Install Command Line Tools. xcode-select --install — that's the whole toolchain.

2

Build and run. The island appears at the top of your screen on first launch.

3

Grant permissions once. Screen recording for screenshots, accessibility for hotkeys.
