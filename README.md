# tinynotch

MacBook notch island: AI agents with approvals, 100 built-in tools, music, clipboard, shelf, notifications. Swift + SwiftUI, no Xcode required (Command Line Tools only).

## Build

```bash
./scripts/make-dmg.sh   # -> build/Notchly-<version>.dmg
```

or `./build.sh` for just the app.
