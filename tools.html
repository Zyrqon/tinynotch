Tool packs

TinyNotch ships with 28 core tools built in. Everything else comes as packs — like add–ons in Blender. Build from source and all 100 tools are already on.

1.Download a pack below (.json file).
2.In TinyNotch: Tools tab → “Packs folder” button.
3.Drop the .json in and toggle “Base” off. The pack is installed.
